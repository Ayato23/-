# お金を稼げる人間になるためのロードマップ

このリポジトリ（仮眠最適化アプリ）を「練習台」兼「実績（ポートフォリオ）」として使い、
アプリ開発でお金を稼げる力を段階的に身につけるための道筋です。

> ポイント: お金は「誰かの困りごとを解決したこと」への対価として生まれます。
> 技術を覚えること自体がゴールではなく、「人の役に立つものを作って届けられる」ことがゴールです。

---

## ステップ1: 自分のアプリを理解して、自分で直せるようになる（〜1か月）

**目標**: このアプリのコードを自分の言葉で説明できる。

- [ ] `src/app/` の各画面が、どのファイルで作られているか説明できる
- [ ] `src/lib/storage.ts` で、データがどう保存されているか説明できる
- [ ] ボタンの文言や色を、自分で変えてブラウザで確認できる
- [ ] Git で「add → commit → push」を自分で実行できる

**稼ぐ力との関係**: 仕事では「既存のコードを読んで直す」作業が一番多いです。

## ステップ2: 自分で機能を1つ追加する（〜2か月）

**目標**: 小さな機能を、自分で考えて最後まで作り切る。

アイデア例（このアプリ向け）:
- [ ] 仮眠の記録を削除・編集できるようにする
- [ ] 仮眠タイマー終了時に音やバイブで知らせる
- [ ] 記録をCSVで書き出せるようにする

**稼ぐ力との関係**: 「言われたものを作り切れる」ことが、お金をもらえる最低ラインです。

## ステップ3: 人に使ってもらう（〜3か月）

**目標**: 自分以外の人に使ってもらい、感想をもらう。

- [ ] Web版を公開する（Expo の Web 書き出し + 無料ホスティング）
- [ ] 友人・家族など3人に使ってもらう
- [ ] もらった感想をもとに1つ改善する
- [ ] README にスクリーンショットと「工夫した点」を書く

**稼ぐ力との関係**: 「使う人の声を聞いて改善する」力は、どんな仕事でも価値になります。
完成したアプリと README は、そのまま **ポートフォリオ（実績）** になります。

## ステップ4: 最初の1円を稼ぐ（3か月〜）

**目標**: 小さくてもいいので、実際にお金を受け取る経験をする。

選択肢（どれか1つでOK）:
- **小さな受託**: クラウドソーシング（ランサーズ、ココナラ等）で、Webページ修正などの小さな案件を受ける
- **アプリ公開**: App Store / Google Play に公開する（課金・広告は後から）
- **発信**: 作ったものや学んだことを Zenn / Qiita / note に書く（仕事の声がかかるきっかけになる）

**稼ぐ力との関係**: 金額よりも「価値を提供して対価をもらう」流れを一度体験することが大切です。

## ステップ5: 稼ぎを大きくする（半年〜）

- 実績が増えたら、単価の高い案件や、エンジニアとしての就職・転職も視野に入れる
- 得意分野（例: React Native、健康系アプリ）を決めて、強みを作る
