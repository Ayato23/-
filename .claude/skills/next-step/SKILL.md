# 次の一歩を進める手順

1. `docs/ROADMAP.md` を読み、チェックが付いていない一番最初の項目を見つける。
2. その項目について、ユーザーに次のことを日本語でかみ砕いて伝える。
   - 何をするのか（1〜2文）
   - なぜそれが「稼ぐ力」につながるのか（1文）
   - 関係するファイルの場所
3. 答えをすぐに書かず、まずユーザー自身に試してもらう。
   - 詰まったら、ヒントを小出しにする（いきなり完成コードを渡さない）。
4. ユーザーができたら、Webブラウザで動作確認する手順を伝える。
5. 確認が取れたら、ユーザーの了承を得てから ROADMAP.md の該当項目に `[x]` を付け、
   Git の add → commit → push をコマンドの意味を説明しながら行う。
6. 最後に、次に取り組む項目を1つだけ予告する。
