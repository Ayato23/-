# 仮眠最適化アプリ (Phase1 MVP)

ビジネスパーソン向けに、仮眠の条件(時間帯・場所・姿勢)と仮眠後のパフォーマンス(集中力・眠気)を記録し、
自分にとって最も効果的な仮眠パターンを発見できるアプリです。前夜の睡眠時間から簡易的な「睡眠負債」も可視化します。

React Native (Expo) + expo-router で構築。センサー連携・アカウント・サーバーなし、すべてローカル保存(単一ユーザー)。

## 機能 (Phase1)

- ホーム画面: 今日の睡眠負債サマリー、仮眠/睡眠記録への導線
- 仮眠タイマー: 場所(デスク/車内/仮眠スペース/その他)・姿勢(座位/半横臥/その他)を選択し、20分デフォルト(変更可)でカウントダウン
- 仮眠後の評価: 集中力・眠気・気分(任意)を5段階で記録
- 睡眠記録: 就寝・起床時刻から睡眠時間を自動計算(手入力での上書きも可能)し、目標睡眠時間との差分から睡眠負債を算出
- 週次グラフ: 睡眠負債の推移(直近7日)、仮眠パターン別(場所別・時間帯別)の平均パフォーマンススコア比較

データは端末の AsyncStorage にのみ保存されます。

## セットアップ

```bash
npm install
npx expo start
```

- `w` でWebプレビュー、`a`/`i` でAndroid/iOSシミュレータを起動できます(要環境構築)。

## ディレクトリ構成

```
src/
  app/            expo-router のルート定義(画面)
    (tabs)/       ホーム・週次グラフ(タブ)
    nap/          仮眠タイマー・仮眠後評価
    sleep/        睡眠記録入力
  components/     再利用UIコンポーネント
  lib/            データモデル・ストレージ(AsyncStorage)・日付ユーティリティ
```

## Phase1でやらないこと

- 仮眠スポットの検索・地図表示
- 他ユーザーとの共有・SNS機能
- プッシュ通知
- 睡眠センサーによる自動計測
